# Khalid Javaid Mir — Portfolio

This is a free, static portfolio site designed for GitHub Pages.

## Publish it

1. Create a **public** GitHub repository named `iamkhalidcse.github.io`.
2. Extract the ZIP on your computer. Upload the extracted files and the `assets` folder to the repository's main branch. Do not upload the ZIP itself or put everything inside an extra parent folder.
3. Keep this structure at the repository root:

   ```text
   index.html
   styles.css
   README.md
   assets/
     khalid-slate-portrait.png
   ```

4. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. After GitHub finishes publishing, the site will be available at `https://iamkhalidcse.github.io`.

## Preview and edit

Keep the files together. Open `index.html` in a browser to preview the site locally. Edit `index.html` for wording and `styles.css` for appearance. The fonts load from Google Fonts; the site uses fallback fonts when offline.

This package contains only the current portfolio page, styling, and edited portrait. It does not include the local Git history, original photo, resume PDF, or work files.

No paid hosting or server is required.
